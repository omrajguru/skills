# Skills by Om Rajguru

[![skills.sh](https://skills.sh/b/omrajguru/skills)](https://skills.sh/omrajguru/skills)

Agent skills for writing, design, video, and shipping better apps. Every skill I publish, in one place.

## Install

```bash
npx skills@latest add omrajguru/skills
```

Each skill also lives in its own repository with its own install command. Those still work, and stay the home for each skill's full docs and releases.

## Reference

- **[dailies](./skills/dailies/SKILL.md)** — Make finished videos with Claude Code or Codex, from an idea or your own footage, with approval frames before the full render. ([repo](https://github.com/omrajguru/dailies))
- **[plainspoken](./skills/plainspoken/SKILL.md)** — Write technical articles, docs, and READMEs in your own voice, without AI slop. ([repo](https://github.com/omrajguru/plainspoken))
- **[interruptions](./skills/interruptions/SKILL.md)** — Find the edge cases that break your app across 12 categories, audit them, then fix them in severity order once you approve. ([repo](https://github.com/omrajguru/interruptions))
- **[app-launch-readiness](./skills/app-launch-readiness/SKILL.md)** — Audit your app before launch and get a readiness score, ranked issues, exact fixes, and copy-paste prompts. ([repo](https://github.com/omrajguru/launch-readiness))
- **[hig-compliance-auditor](./skills/hig-compliance-auditor/SKILL.md)** — Scan code and designs against Apple's Human Interface Guidelines, get an audit with severity tiers, and apply fixes on approval. ([repo](https://github.com/omrajguru/hig-compliance-auditor))
- **[brand-social-design](./skills/brand-social-design/SKILL.md)** — Generate brand-consistent social media graphics as exportable HTML, with a brand onboarding interview and memory. ([repo](https://github.com/omrajguru/brand-social-design))

## Install one skill

```bash
npx skills@latest add omrajguru/skills --skill plainspoken
```
